Convert String To Json - ASP.NET Web Forms / .NET Framework 4.8

Buka ConvertStringToJson.sln di Visual Studio 2022. Pastikan workload ASP.NET and web development dan .NET Framework 4.8 Developer Pack terpasang. Jalankan dengan F5 melalui IIS Express.

Default.aspx berasal dari index.html. Asset Monaco Editor dan CSS tetap disertakan. Fungsi format/escape JSON berjalan di JavaScript browser; code-behind C# disediakan untuk integrasi server-side. Build belum diuji pada Visual Studio Windows.
